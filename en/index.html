What Stuzhik does

When the game crashes

The game crashed? The cause and what to do

Reads the crash report and names the mod the game crashed in. Then steps with buttons: update, disable, send the logs to the author.

90 of 93real crashes: the cause named right

Conflicts show before launch

Mods for another version and missing dependencies show up before the game crashes. What is missing installs with one button.

Mod overlaps

Which mods change the same game methods, where ores and recipes repeat. Reads the jar files without running anything.

Builds

Build translation

Quests, books and KubeJS texts: see how much is in Russian. What is missing comes from other versions of the same mods.

Version change with rollback

the whole build with worlds is saved first

Modpack updates, no surprises

see what will change first

Backups without repeats

identical files are stored once

Modpack builder

a modpack as a project, nothing installed

Play

A build for a friend, no servers

A friend on the same network or a shared VPN takes your build straight from your computer.

A build in Steam

starts from Big Picture and on Steam Deck

Your own server

a console with RCON, restart on crash

Graphics presets

shader and Sodium, Iris for any build
