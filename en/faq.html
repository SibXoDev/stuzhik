FAQ ​

General questions ​

How is it different from other launchers? ​

Crash analysis: Finds the mods to blame and suggests solutions. Other launchers only show the log.

Performance: Fast startup, low resource usage.

Live monitoring: Tracks problems while you play.

Stuzhik Connect: Direct transfer of modpacks and builds to friends without uploading them to third-party services — see Stuzhik Connect.

Mod collections: Sets of mods not tied to a version — applied to any instance with one click, see Mod Collections.

Are Fabric/Forge/NeoForge/Quilt supported? ​

Yes, all 4 loaders + Vanilla.

Can I use it with existing instances? ​

Yes. Import from:

  • MultiMC/Prism Launcher
  • Modrinth modpacks (.mrpack)
  • CurseForge modpacks (.zip)

Do I need a Minecraft account? ​

Yes, you need to use a Microsoft account that owns Minecraft: Java Edition.

What does Stuzhik send about itself? ​

Only anonymous statistics, and only with your consent — on first launch the launcher shows the user agreement, and nothing is sent until you answer. Once a day — the launcher version and its channel, the operating system and its bitness, the interface language, "first launch of the day, week, month" marks, the date of the first launch, the invitation code if you came by one, and your answer to "How did you hear about Stuzhik?" if you gave one. While the launcher is open — a short pulse: a random session number (new at every launch) and which Minecraft versions with which loaders are running right now.

There is no nickname, no accounts, no build names, none of your files and no persistent install identifier; the server doesn't store IP addresses — it only looks up the country from them. The full list is in the agreement itself. To turn it off: Settings → Privacy → "Send anonymous statistics"; the launcher works the same without it.

How do I remove Stuzhik completely? ​

Like any program: Windows Settings → Apps → Stuzhik → Uninstall. Service data, saved account logins and the firewall rule always go, while builds and worlds go only if you tick "Also delete builds and worlds (all launcher data)". More — Uninstalling.

Performance ​

Why does Forge take so long to install? ​

The Forge installer downloads libraries from maven.minecraftforge.net. This takes 1-3 minutes.

Stuzhik uses BMCLAPI mirrors to speed this up.

How much space does an instance take? ​

ComponentSize
Minecraft~200MB
Forge/Fabric~50MB
Mods (10-50)~100-500MB
Total~400-800MB

Can I run several instances at the same time? ​

Yes, with no limits.

Mods ​

How do I install a mod? ​

Option 1: Catalog

  1. Open the instance → Mods → Catalog
  2. Find the mod → Install

Option 2: File

  1. Open the instance → Mods
  2. The "Add" button or drag & drop a .jar

Does Stuzhik update mods automatically? ​

Not by default. You can turn it on for each mod:

  1. Mod list → click the mod
  2. Turn on "Auto-update"

What do I do about a mod conflict? ​

Stuzhik warns you BEFORE installing if it knows about the conflict.

If a crash has already happened:

  1. Log Analyzer → finds the mod to blame
  2. The "Remove mod" or "Replace with a compatible one" button

Where are mods stored? ​

On Windows:

C:\Users\<username>\AppData\Roaming\ru.sibxodev.stuzhik/instances/<instance_id>/mods/

Stuzhik Connect ​

Is it safe? ​

Yes. The connection is encrypted entirely (QUIC with TLS 1.3), the launcher recognizes a friend by a signature made with their key, and a modpack is taken from you only after you click "Allow" (that's the default; in the "Sharing modpacks" settings, "Ask for permission" can be switched to "Except friends" or "Never"). Executable files are never transferred. More in Stuzhik Connect.

Do I need to open ports on my router? ​

For a local network — no, devices find each other by themselves. For friends outside your network (different homes/cities), a shared VPN is the easiest — then you don't need to forward ports. In Radmin VPN, ZeroTier and Hamachi, discovery works like on a LAN; in Tailscale, you add your friend by address once, and after that the launcher finds them by itself. On Windows you need one firewall rule, "Stuzhik Connect" — the button in the "Friends" section adds it.

Does it work directly over the internet, without a VPN? ​

No, if you're on different networks. Stuzhik has no server of its own for connecting over the internet — it finds and connects devices only within one network (real, or virtual through a VPN). If you're physically on the same LAN, it just works; if not, you need a shared VPN, see Stuzhik Connect.

Problems ​

OutOfMemoryError ​

Cause: Not enough RAM allocated.

Solution:

  1. Open the instance → Edit
  2. Increase RAM (4-6GB recommended for modpacks)
  3. Save → Restart

The game won't launch ​

Check:

  1. Dev Console → are there any errors?
  2. Log Analyzer → finds the problem automatically
  3. Is Java installed? (Stuzhik installs it automatically, but something may have gone wrong)

Mods don't load ​

For Forge:

  • The file must be for Forge (-forge- in the name)
  • The Minecraft version must match

For Fabric:

  • Fabric API is required (installed automatically)
  • The file is for Fabric (-fabric- in the name)

Crash mentioning "Mixin" ​

Cause: A conflict between mods that modify the same code.

Solution:

  1. Log Analyzer shows the conflicting mods
  2. Remove one of the conflicting mods
  3. Or use an alternative mod
