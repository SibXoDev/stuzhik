Known issues ​

Bugs we know about and haven't fixed yet — with workarounds where there are any. A fixed bug leaves the list with the release that fixes it (see the Changelog). What we're doing next is on the roadmap.

Found something that isn't here? Write to us on Telegram — what you did and what you saw; the launcher log opens with Ctrl+Shift+D.

On the list now: 36

Instances

A cleared field in instance editing is not saved

Setting Java back to “Automatic”, resetting JVM parameters or erasing the nickname, notes or loader version in “Edit” keeps the old value after saving.

Workaround: Set the value you want explicitly instead of leaving the field empty.

Deleting an instance does not stop the game

Deleting an instance while it is being played leaves the game running on files that are already gone.

Workaround: Close the game before deleting the instance.

Duplicating does not wait for the game or an install

An instance can be duplicated while it is running or installing — the copy comes out unfinished, and backups are copied too.

Workaround: Duplicate an instance when it is neither running nor installing.

Tabs show the previous instance

Opening another instance while “Console” or “Backups” is open in the details can leave the tab on the previous instance.

Workaround: Switch to another tab and back.

Launch history is off by one entry

Changes in the launch history show up under the neighbouring session.

Live log analysis does not start

While the game is running, live log analysis never starts.

Workaround: Open the log analyzer after quitting the game — analysing a finished log works.

Mods

CurseForge mods are not marked “Installed”

A CurseForge mod already in the build is not marked “Installed” in the catalog.

Workaround: Check the instance’s Mods tab after installing.

“Install missing” loses failures

If some of the missing mods fail to install, nothing reports it.

A dragged-in jar duplicates a mod

A jar dropped into Mods shows up as a second copy if the same mod is already installed from the catalog.

Workaround: Remove the extra copy by hand.

Recommendations install the wrong version

A recommended mod may install a version that is not for your game or loader.

Workaround: Install the mod from the catalog — there the version is matched to the instance.

Mods become “local” for good

If Modrinth or CurseForge did not answer during the check, mods are marked as not from a platform and stay that way.

“Not a problem” still counts

A conflict marked “Not a problem” is hidden from the list but still counted in the numbers.

Modpacks

Resource packs and shaders from a CurseForge modpack don’t show in the game

Installing or updating a CurseForge modpack puts them into the mods folder.

Workaround: Move them from mods to resourcepacks or shaderpacks by hand.

CurseForge installs the latest mod version

Installs, dependencies and updates from CurseForge take the mod’s latest file without checking whether it fits alongside the rest. Modrinth has this check.

Workaround: If a mod doesn’t start, pick its version by hand in the mod’s card.

A modpack update loses a mod that failed to download

If a mod’s new file fails to download, the old one is removed anyway and the instance counts as updated.

Workaround: A backup is made before the update — you can roll back from it.

Install progress from a modpack card is hidden

Progress, cancel and errors of an install started from a modpack card are drawn underneath the card.

Workaround: Close the card — the install shows in Downloads.

Optional groups on import

A Builder modpack shows its optional groups as cryptic codes instead of names on import, and the choice is ignored.

Files of a .mrpack outside mods don’t install

The preview lists them, but they never reach the instance.

Builder export and the file name

The export ignores the file name you set, and “:” or “?” in the title break it on Windows.

Workaround: Don’t use “:” or “?” in the modpack title.

Game install

NeoForge for Minecraft 1.21

For “1.21” the list shows every 21.x version, and “Auto” installs the one for 1.21.11.

Workaround: Pick the NeoForge version by hand: 21.0.x for 1.21.

Download settings don’t work as labelled

“Maximum concurrent downloads” has no effect, and the speed limit applies to each file rather than to all of them together.

System Java replaces the installed one

If the system has Java of the same version, the launcher may quietly use it instead of its own.

Workaround: Pick Java explicitly in the instance settings.

Server

Whitelist, OP and bans for offline players

On a server without licence checks the whitelist, OP and ban buttons have no effect.

Workaround: Use commands in the server console.

Server settings mangle “numeric” text

Saving settings mangles text properties that look like numbers: the world seed, the RCON password.

Workaround: Edit such properties in server.properties by hand.

Joining a server with an invite code

By default joining with a code is refused, and the address in the invite is 127.0.0.1.

RCON gets out of step

After a long reply or a timeout RCON replies start arriving for the wrong commands. A “Stopping server” line in the chat switches RCON off entirely.

Players and TPS in the server console

The console always shows 0 players, and TPS over RCON is calculated wrong.

A server gets stuck in “Restarting…”

After a restart a server can stay in “Restarting…” for good.

The server import window

Port and slot count are empty, and “Close” does not add the server to the list.

Friends and Connect

“Get the pack” sits at 0%

Throughout the transfer the progress shows 0% and “Connecting”.

Pausing and cancelling a send

Pause and cancel on the sending side don’t stop the transfer. The owner also always sees “Transfer complete”, even after a drop.

A declined friend request is not delivered

Whoever sent the request never learns it was declined.

Cancelling a download leaves the question open

Cancelling a download leaves the consent question open on the owner’s side.

A firewall rule from an older version

If the firewall rule was set up before 0.0.19, the connection screen says everything is fine, yet connections to friends don’t establish.

Workaround: Press “Add firewall rule” in the Friends section again.

A friend behind a VPN vanished after a network change

If both of you changed network or port while one was offline, friends can’t find each other without local network discovery.

Workaround: Add the friend by address again.

The sender doesn’t see skipped files

Files that are not sent by the safety rules (a .dll next to a mod, for example) are shown to the receiver only.
