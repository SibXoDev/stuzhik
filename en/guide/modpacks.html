Modpacks ​

A modpack installs as a separate build and remembers where it came from: it can be updated, compared with other versions and handed to friends.

Catalog ​

The «Modpacks» section in the sidebar, with the tabs «Search», «From file», «By link» and «Compare».

  • Search: Modrinth and CurseForge. A game version filter installs the pack's version for that game version, not the newest one: the install window shows in advance which version goes in and lets you pick another. A pack's version list filters by game version, channel and loaders
  • From file: .stzhk, .mrpack (Modrinth) or .zip (CurseForge). The file can also just be dropped onto the window
  • By link: a .stzhk from cloud storage

While a modpack installs, the window shows the pack's archive as one bar with its size and speed, and the game's and mods' files as one counter. «Cancel» stops the install from the first second, even while the archive downloads.

A Modrinth modpack installs as its author marked it: a file marked «not needed» on the client or on the server does not go there, and a server takes its own part of the pack.

Export ​

«Export build» in the build's menu. Formats:

FormatFor whom
STZHKfor Stuzhik: links to the mods and, if you want, the files themselves inside
Modrinthfor Prism, MultiMC, Modrinth App
CurseForgefor CurseForge App; mods it does not have go into the archive as files
Universal ZIPfor friends without a launcher: all files and a README with instructions

Before exporting you can pick which mods and files to leave out.

Updating a modpack ​

The «Modpack» tab of the build page. «Check for updates» finds a new version, «Show changes» opens «What will change»: which mods are added, updated and removed. Your own mods are marked apart («Your own mods — untouched»).

No need to open every build: once per start the launcher checks all builds from modpacks, and a build with a new pack version gets «Update» on its card. Clicking it opens the «Modpack» tab. The «Check modpack updates» button next to the build search checks again.

  • «Create a backup first», «Keep my own mods», «Overwrite configs» as you choose
  • «Update» updates this build, «Install separately» puts the new version next to it
  • An update is counted for the build: «New versions available» means only pack versions for the same Minecraft version and loader. Newer versions for another game or loader are shown on a line of their own: you can pick one in the list, but that is a move, not an update
  • A pack mod you updated by hand is replaced with the pack's version when the pack updates, instead of staying next to it (two copies of one mod crashed the game). To keep yours, pin the mod's version («Pin the version»)
  • Disabled mods stay disabled: the new version of such a mod is installed disabled too. On a server, client-side mods are turned off again after an update
  • A new pack version for another Minecraft version: before the update the launcher saves the whole build with its worlds, even with backups off. Until you press «Keep», «Roll back» on the build page brings back the files, worlds, mods and the pack's version number, as with a game version change

«Restore as in the pack» compares the mods folder with the installed pack version and brings it back:

  • deleted pack mods are downloaded again, changed files and mods moved to another version are replaced with the pack's files
  • as you choose: turn the pack's turned-off mods back on, remove your own mods, restore the pack's configs
  • the pack's resource and shader packs missing from the build come back, changed ones are replaced with the pack's files (this can be turned off); a pack made shared for all builds and a turned-off pack are not put back into the build

The window shows all of it before anything changes, a backup is made by default.

A server from a modpack on Linux without a window is updated with stuzhik-cli update: console version.

Translations from the Stuzhik team ​

The Stuzhik team translates modpacks into Russian by hand, without machine translation. The launcher asks our server which packs are translated already and lays the translation over the build by itself after it is installed or updated. The list grows: a newly translated pack is picked up without a launcher update. «Ask» or off: «Settings → Mods → Build translations». A translation you removed by hand does not come back by itself, and the launcher does not replace your own translation file. To translate a build yourself: Builds → Build translation.

Comparing ​

The «Compare» tab in «Modpacks»: two modpacks, each a file, a build or a catalog pack of the version you need. You see mods only in one of them, mods at different versions and differences in configs and other files.

Handing it to friends ​

Through Stuzhik Connect: you open the build to friends, a friend takes it on their side, the files go directly. Without Connect, export to .stzhk and send the file any way you like: your friend imports it on the «From file» tab.

If something is wrong ​

The install takes too long. «Cancel» in the install window stops it, from the first second.

The game crashed after installing. The Log Analyzer names the cause and offers what to do.
