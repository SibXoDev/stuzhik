Modpacks ​

Stuzhik format (.stzhk) ​

Stuzhik uses its own modpack format, .stzhk - optimized for fast installation and maximum compatibility.

Advantages ​

  • Fast installation - optimized structure
  • Full compatibility - all settings are kept
  • Compact size - efficient compression
  • Metadata - version, author, description, screenshots

Exporting to .stzhk ​

  1. Open the instance
  2. "Export" button → "Stuzhik (.stzhk)"
  3. Fill in the metadata
  4. Save the file

Importing .stzhk ​

Just drag the .stzhk file into the Stuzhik window, or:

  1. Home → "Import"
  2. Choose the file
  3. Done

Compatibility with other formats ​

Stuzhik also supports importing from popular formats:

FormatSourceSupport
.stzhkStuzhikFull
.mrpackModrinthFull
.zipCurseForgeFull

Importing from Modrinth ​

  1. Home → "Modpack"
  2. Search by name
  3. Choose a version → "Install"

Importing from CurseForge ​

  1. Download the .zip from CurseForge
  2. Stuzhik → "Import"
  3. Choose the file

Creating a modpack ​

What's included ​

  • The mod list with versions
  • Mod configs
  • Game settings
  • Resource packs and shaders (optional)

What's NOT included ​

  • Minecraft (downloaded separately)
  • The loader (installed automatically)
  • World saves

Modpack editor ​

Comparing versions ​

  1. The "Modpacks" section in the sidebar → the "Compare" button
  2. Pick the first and second modpack: a file, an instance, or a modpack from Modrinth/CurseForge (with the version you need)
  3. You'll see:
    • Mods only in the first and only in the second
    • Mods with different versions
    • Differences in configs and other files

Updating ​

  1. Open the instance with the modpack
  2. "Check for updates"
  3. Apply the changes

Server modpacks ​

When exporting for a server, Stuzhik automatically:

  • Excludes client-only mods
  • Adds server-only mods
  • Configures server.properties

Syncing with friends ​

Through Stuzhik Connect (recommended) ​

Direct transfer with no intermediate files, and everything downloads P2P. You can't send a modpack to a friend: Connect only works by "pulling". Open the modpack to friends ("Sharing" → "Friends only"), your friend takes it on their side with the "Get" button, and by default your launcher asks for your permission — the files start moving only when you click "Allow". More in Stuzhik Connect.

Manually ​

If Connect doesn't suit you (for example, you're sending it through a messenger or on a USB stick):

  1. Export the modpack to .stzhk
  2. Send it to your friends any way you like
  3. They import the file into Stuzhik
  4. Everyone is on the same versions

Troubleshooting ​

Installation is stuck ​

Dev Console (Ctrl+Shift+D) shows the details. Possible causes:

  • A slow connection
  • An unavailable mod

Crash after installation ​

Log Analyzer automatically finds the problematic mods and suggests solutions.
