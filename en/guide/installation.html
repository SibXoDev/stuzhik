Installation ​

System requirements ​

Minimum ​

  • RAM: 4GB (8GB recommended)
  • Disk space: 2GB + space for instances
  • OS: Windows 10+

Recommended ​

  • RAM: 16GB
  • Disk space: SSD with 20GB free
  • GPU: Any with OpenGL 3.3+ support

Download ​

Download for Windows.exe · Windows 10 or newer

Windows only: macOS and Linux are not planned any time soon

  1. Download the installer with the button above
  2. Run the downloaded installer
  3. Follow the installer's instructions

There are no macOS or Linux builds, and none are planned any time soon.

Updating ​

Stuzhik checks for updates automatically at startup and installs the new version by itself.

To configure it: Settings → "General" → the "App Updates" section:

  1. "Check for updates on startup" — turn it off if you don't want automatic updates
  2. "Update channel" — "Stable" or "Beta"

To check by hand — in the same place, the "Check now" row → the "Check for updates" button. You can also just download the new installer and run it over the old one: builds, worlds and settings stay.

Uninstalling ​

Stuzhik is removed like any other program: Windows Settings → Apps → Stuzhik → Uninstall.

What goes away on removal:

  • Always — service data: cache, logs, error reports, the built-in browser's data, saved account logins (they live in the Windows Credential Manager) and the firewall rule for Stuzhik Connect. To remove the rule, Windows asks for administrator confirmation once — only if the rule was created
  • Only with the checkbox "Also delete builds and worlds (all launcher data)" — builds, worlds, settings, Java and game files. Without it they stay, and after reinstalling everything is in place

Updating the launcher touches none of this.
