Mod Collections ​

A set of mods not tied to a specific Minecraft version or loader. You put it together once and apply it to any instance, and Stuzhik picks the right mod versions for it by itself.

This isn't a modpack: a collection contains no configs or settings — only the list of mods you usually install together.

Why you need it ​

A modpack pins versions. A collection doesn't. If you have a go-to set of your favorite mods (say, optimization + QoL) and you keep creating new instances for different MC versions — instead of reinstalling the same set by hand, you apply the collection, and the right versions are picked automatically for that particular instance.

Creating a collection ​

From scratch ​

  1. The "Mod Collections" section in the sidebar → type a name into the "Collection name…" field and click "+" ("Create collection"). With the field empty, "+" asks you for a name
  2. A description (optional) — the "Edit collection" pencil next to the name
  3. Add mods through the built-in catalog — the "Catalog" switch above the collection's mod list, with an "Add" button on each mod. Search, filters, everything just like in the regular mod browser

From an installed instance ​

  1. The "Mod Collections" section → the "From instance" button → pick the instance
  2. Choose which mods to include (you don't have to take all of them). Only Modrinth and CurseForge mods are listed — local JARs can't be matched to another game version
  3. Where to: "To a new collection" (give it a name) or "To “…”" — the collection that's open right now. Then "Add"

Applying a collection ​

To an existing instance ​

  1. Instance → "Mods" tab → the "Mod Collections" button (tooltip "Apply")
  2. Choose a collection
  3. Stuzhik shows a preview: what will be installed, what will be skipped (already there or incompatible), and what couldn't be found for this version/loader
  4. Confirm with "Install selected"

When creating a new instance ​

The instance creation form has an optional "Mod collection" field (it shows up once you have collections, and not for a vanilla instance) — the mods are installed right after the instance is created, with versions picked for its MC version and loader.

Export and import ​

  • To a modpack — a collection can be exported to .mrpack (Modrinth) or .stzhk (Stuzhik format), pinning the versions for a specific MC version
  • Importing a modpack into a collection — it works the other way around too: take an existing modpack (Modrinth or CurseForge) and save its mod list as a version-independent collection

Management ​

  • Duplicate a collection — if you want to make a variation without touching the original
  • Renaming, a custom icon
  • Sorting the mods within a collection: "By date added", "By name" or "By source"
