Servers ​

Your own Minecraft server right from the launcher: create it, add mods, start it and run it from the console. It is a build like any other, only without graphics: with its own mods, world and settings. For a server on Linux without a window there is a console version: it shares its data with the app.

Creating ​

  • «Create» → server: the game version and a loader, as for a client
  • Importing a server: Ctrl+K → «Import» → the «Server» tab, then «Server Folder» with a ready server. The launcher finds out the game version, loader, port and number of players by itself
  • «Convert to Server» in a client build's menu: client mods (minimaps, shaders, interface) are turned off by themselves

Without accepting the Minecraft EULA the server doesn't start: the launcher asks for it before the first start.

Server tabs ​

Analyze Logsanalysis of a server crash (Log Analyzer)

On the «Mods» tab, «Client-only mods» finds the mods the server doesn't need and turns them off.

Console ​

The server's output live, an «All» / «Errors» filter and command history with the ↑↓ keys. «Stop server (stop)» saves the world; «Force Kill» cuts the process off and may lose data.

If RCON is on, commands go through it, the console shows how many players are online, and «Say» works: a message to all players. RCON is off by default: turn it on and set a password in «Server Settings» → «Settings» → «RCON». The password lives in server.properties, so don't open the RCON port to the internet.

Server settings ​

  • Settings: server.properties by group: network, world, gameplay, performance, security, RCON, Query. Values are saved as written (a long world seed doesn't turn into another number). Changes take effect after a restart
  • Players: whitelist, operators and bans. On a server without licence checks it works with offline names too
  • EULA: accept the Minecraft agreement

In «Edit», a server has its port and «Restart on crash»: a crashed server comes back up by itself.

Friends' servers ​

«Friends» shows the servers your friends have opened and the ones they are playing on now. For each you see how it is right now: latency, how many players are online, the version and the server message, as in the game's own server list. The launcher asks the server when you open its room and when you press «Ask again»; if it doesn't answer, it says so.

«Join» downloads the server's build (or fetches what is missing), fills in the address and starts the game. More about friends and passing builds: Stuzhik Connect.
