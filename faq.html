FAQ ​

Общие вопросы ​

Чем отличается от других лаунчеров? ​

Анализ крашей: Находит виноватые моды и предлагает решения. Другие лаунчеры только показывают лог.

Производительность: Быстрый запуск, малое потребление ресурсов.

Live мониторинг: Отслеживает проблемы во время игры.

Stuzhik Connect: Прямая передача модпаков и сборок друзьям без загрузки на сторонние сервисы — см. Stuzhik Connect.

Сборки модов: Наборы модов без привязки к версии — применяются к любому экземпляру одной кнопкой, см. Сборки модов.

Поддерживается ли Fabric/Forge/NeoForge/Quilt? ​

Да, все 4 загрузчика + Vanilla.

Можно ли использовать с существующими экземплярами? ​

Да. Импорт из:

  • MultiMC/Prism Launcher
  • Modrinth модпаки (.mrpack)
  • CurseForge модпаки (.zip)

Требуется ли аккаунт Minecraft? ​

Да, нужно использовать Microsoft аккаунт с купленным Minecraft: Java Edition.

Что Stuzhik отправляет о себе? ​

Только анонимную статистику и только с вашего согласия — при первом запуске лаунчер показывает пользовательское соглашение, и пока вы не ответите, не уходит ничего. Раз в сутки — версия лаунчера и её канал, операционная система и её разрядность, язык интерфейса, отметки «первый запуск за день, неделю, месяц», дата первого запуска, код приглашения, если вы пришли по нему, и ответ «Как вы узнали о Stuzhik?», если ответили. Пока лаунчер открыт — короткий пульс: случайный номер сеанса (новый при каждом запуске) и какие версии Minecraft с какими загрузчиками сейчас запущены.

Ни ника, ни аккаунтов, ни названий сборок, ни ваших файлов, ни постоянного идентификатора установки там нет; IP-адрес сервер не сохраняет — только определяет по нему страну. Полный список — в самом соглашении. Выключить: Настройки → Приватность → «Отправлять анонимную статистику», лаунчер работает без неё так же.

Как удалить Stuzhik полностью? ​

Как обычную программу: Параметры Windows → Приложения → Stuzhik → Удалить. Служебные данные, сохранённые входы в аккаунты и правило брандмауэра уходят всегда, а сборки и миры — только если отметить «Удалить также сборки и миры (все данные лаунчера)». Подробнее — Деинсталляция.

Производительность ​

Почему Forge устанавливается долго? ​

Forge installer загружает библиотеки с maven.minecraftforge.net. Это занимает 1-3 минуты.

Stuzhik использует зеркала BMCLAPI для ускорения.

Сколько места занимает экземпляр? ​

КомпонентРазмер
Minecraft~200MB
Forge/Fabric~50MB
Моды (10-50шт)~100-500MB
Итого~400-800MB

Можно ли запустить несколько экземпляров одновременно? ​

Да, без ограничений.

Моды ​

Как установить мод? ​

Вариант 1: Каталог

  1. Открой экземпляр → Моды → Каталог
  2. Найди мод → Установить

Вариант 2: Файл

  1. Открой экземпляр → Моды
  2. Кнопка "Добавить" или drag&drop .jar

Stuzhik автоматически обновляет моды? ​

По умолчанию нет. Можно включить для каждого мода:

  1. Список модов → клик на мод
  2. Включи "Автообновление"

Что делать при конфликте модов? ​

Stuzhik предупредит ДО установки если знает о конфликте.

Если краш уже произошёл:

  1. Анализатор логов → найдёт виновный мод
  2. Кнопка "Удалить мод" или "Заменить на совместимый"

Где хранятся моды? ​

На Windows:

C:\Users\<username>\AppData\Roaming\ru.sibxodev.stuzhik/instances/<instance_id>/mods/

Stuzhik Connect ​

Это безопасно? ​

Да. Соединение целиком шифруется (QUIC с TLS 1.3), друга лаунчер узнаёт по подписи его ключом, а сборку у тебя забирают только после твоего «Разрешить» (так по умолчанию; в настройках выдачи «Спрашивать разрешение» можно переключить на «Кроме друзей» или «Никогда»). Исполняемые файлы не передаются никогда. Подробнее — Stuzhik Connect.

Нужно открывать порты на роутере? ​

Для локальной сети — нет, устройства находят друг друга сами. Для друзей вне вашей сети (разные квартиры/города) проще всего общий VPN — тогда порты пробрасывать не нужно. В Radmin VPN, ZeroTier и Hamachi поиск работает как в локалке; в Tailscale друга один раз добавляют по адресу, дальше лаунчер находит его сам. На Windows нужно одно правило брандмауэра «Stuzhik Connect» — его добавляет кнопка в разделе «Друзья».

Работает через интернет напрямую, без VPN? ​

Нет, если вы в разных сетях. У Stuzhik нет собственного сервера для соединения через интернет — он находит и связывает устройства только в пределах одной сети (реальной или виртуальной через VPN). Если вы физически в одной локалке — работает само; если нет — нужен общий VPN, см. Stuzhik Connect.

Проблемы ​

OutOfMemoryError ​

Причина: Недостаточно RAM выделено.

Решение:

  1. Открой экземпляр → Edit
  2. Увеличь RAM (рекомендуется 4-6GB для модпаков)
  3. Сохрани → Перезапусти

Игра не запускается ​

Проверь:

  1. Dev Console → есть ли ошибки?
  2. Log Analyzer → найдёт проблему автоматически
  3. Java установлена? (Stuzhik устанавливает автоматически, но может быть ошибка)

Моды не загружаются ​

Для Forge:

  • Файл должен быть для Forge (в названии -forge-)
  • Версия Minecraft должна совпадать

Для Fabric:

  • Требуется Fabric API (устанавливается автоматически)
  • Файл для Fabric (в названии -fabric-)

Краш с "Mixin" ​

Причина: Конфликт модов, модифицирующих одинаковый код.

Решение:

  1. Log Analyzer покажет конфликтующие моды
  2. Удали один из конфликтующих
  3. Или используй альтернативный мод
